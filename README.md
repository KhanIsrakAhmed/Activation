# Windows, Office & IDM Activation

A simple reference guide for different activation methods and their supported products.

## Activation Methods

| Activation Type | Supported Product | Activation Period | Internet Required |
|---|---|---|---|
| **HWID** | Windows 10–11 | Permanent | Yes |
| **Ohook** | Microsoft Office | Permanent | No |
| **TSforge** | Windows / ESU / Office | Permanent | Only for StaticCID method on build 26100+ |
| **Online KMS** | Windows / Office | 180 days, renewable | Yes |
| **IDM** | Internet Download Manager | Valid license | Yes |

## Important Notes

- Activation availability may depend on the Windows or Office version.
- A legitimate product key or license should be used whenever possible.
- **IDM requires a valid license** for permanent activation.
- Internet requirements may vary depending on the activation method.

## Supported Products

- Windows 10
- Windows 11
- Microsoft Office
- Internet Download Manager (IDM)
